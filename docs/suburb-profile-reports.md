# Suburb profile PDF library

Place approved PDF reports in `public/reports/suburb-profiles/` using these exact filenames:

- `surfers-paradise.pdf`
- `broadbeach.pdf`
- `broadbeach-waters.pdf`
- `mermaid-beach.pdf`
- `mermaid-waters.pdf`
- `burleigh-heads.pdf`
- `miami.pdf`
- `palm-beach.pdf`
- `currumbin.pdf`
- `coolangatta.pdf`
- `southport.pdf`
- `labrador.pdf`
- `biggera-waters.pdf`
- `runaway-bay.pdf`
- `hope-island.pdf`
- `helensvale.pdf`
- `coomera.pdf`
- `robina.pdf`
- `varsity-lakes.pdf`
- `mudgeeraba.pdf`

The Market Insights page checks for these files automatically. A card becomes an active **View PDF report** link as soon as its matching file is present. Replace a file with the same name to publish an updated edition.

Before publishing, ensure every report includes its publication date, data period, source attribution and a general-information disclaimer.
